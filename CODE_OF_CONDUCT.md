# Code of conduct

Be specific. Be decent. Disagree about the code, not about the person who wrote it.

Do not harass, threaten, or post someone else's private information. Do not paste API keys, client secrets, or account ids. A vulnerability goes through a private advisory, as `SECURITY.md` says.

This repository is a list of names and estimates. Do not ask the maintainers to promise a sale, and do not present a row as if the next buyer will pay the estimate.

Maintainers can edit or close an issue or a pull request that breaks these rules. They can also block a repeat offender from the repository.
